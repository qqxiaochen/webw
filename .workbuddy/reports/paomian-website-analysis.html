3代码质量分析 评分 3.0 / 10

3.1 首页 HTML 结构严重损坏

index.html 由可视化建站工具导出后手工拼接，标签嵌套错乱：第一个 </body></html> 出现在 Discord 图标 SVG 的 <defs> 内部，其后又残留 </defs></svg>、<audio> 和第二个 </body></html>。同时第 199 行 <style type="text/css"> 未闭合就被 </defs> 截断，直到页面尾部才以 </style> 补上。

...
298  </body>
299  </html></style>          ← 这个 /style 实际补的是 199 行未闭合的标签
300    </defs>
301    </svg>                  ← Discord 图标在此才被"关闭"，但 body 已经结束了
302  </div></a>
...
312  <audio autoplay loop style="display:none">  ← 第二个 body 外的音频节点
315  </body>
316  </html>

现代浏览器容错可渲染，但会带来三个实际问题：① SVG 图标样式解析异常（Discord/Telegram 图标可能显示不全）；② 结构非法导致 W3C 校验全挂、SEO 蜘蛛解析歧义；③ 后续维护极易改坏。 该文件正是当前首页处于「待重写」状态的最强信号。

3.3 遗留死代码与过时逻辑

  • yii.js：来自 Yii2 框架（521 行），无任何页面引用，纯死代码。
  • APlayer / Meting：音乐播放器整套组件（JS+CSS 共 73KB）从未被启用。
  • coret.js：IE<9 检测跳转 /view/old——该路径不存在，且 IE9 早已退出市场，逻辑完全失效。
  • UIkit 样式缺失：download.html 用到 uk-scrollspy / uk-toggle / uk-scroll，但 core.css 中未找到对应样式类，动画与滚动行为可能失效。

3.4 工程管理

  • 无 .gitignore：400MB 的 webw.zip 与 .workbuddy/ 未跟踪——若误提交，GitHub 100MB 单文件限制将直接拒绝 push。
  • 提交信息失范：git log 中绝大多数提交信息为「1」，无法追溯变更意图。
  • 无构建/无压缩/无 lint：纯手工维护，CSS/JS 均未压缩、未合并。

5.2 体验问题清单

  • 自动播放背景音乐：Chrome/Safari 会拦截带声音的 autoplay，页面等于「多下 3.2MB 没响」；若被放行则骚扰用户，是典型的负体验。
  • YouTube 嵌入：目标用户含大陆玩家，但 iframe 打不开，形成空白区块。
  • 30MB+ ZIP 直链下载：无速度提示、无镜像；GitHub Pages 下载走 CDN 尚可，但高峰期不稳定。
  • 无缓存/懒加载策略：GitHub Pages 默认强缓存静态资源尚可，但音乐、大图均无条件加载。
  • 移动端：viewport 已声明，但首页按钮、卡片按桌面设计，未做断点适配。

6安全与合规风险 评分 7.0 / 10

6.1 安全面（相对干净）

  • 纯静态、无表单、无 Cookie、无后端 → 无注入/越权面，这是最大的安全优势。
  • 下载文件使用随机文件名（5C72CA.zip、7A638484.zip），降低直链扫描攻击面。好习惯
  • 无外部 CDN 脚本（全部本地文件）→ 无供应链注入面。

6.2 可改进点

  • 缺少 CSP / Referrer-Policy / X-Content-Type-Options 等安全响应头（GitHub Pages 可通过 _headers 文件配置）。
  • 页面明示版本号（VN-211103-2、WE-260812、PH-260806），暴露更新节奏；辅助类产品建议弱化。
  • footer.js 与 jquery.min.js 版本过旧（2013/2014），存在已知漏洞（XSS 向量），建议统一升级。

6.3 业务合规（客观提示，不构成法律意见）

核心事实：本站销售 CF 第三方辅助（外挂），TOS 已声明「可随时封禁授权、对封号不负责」，页脚声明 Except China（不服务中国区），界面以繁中/英文面向海外服玩家。

风险点：① 辅助类业务在多数司法辖区违反游戏用户协议，游戏厂商（Smilegate/Tencent）有权维权并请求平台下架；② 国内对「提供侵入/非法控制计算机信息系统程序工具」有明确刑事规制——尽管站方声明不服务中国区，但 支付渠道 mall.909net.cn 是.cn 备案域名，属于境内基础设施，与「Except China」声明存在矛盾，一旦被认定服务境内用户，风险等级显著上升；③ GitHub Pages 对违反平台政策的内容可随时封禁仓库，域名/支付/代码托管都应准备独立备份与应急切换方案。
