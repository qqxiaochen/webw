🔴 P0 — 严重问题（必须立即修复）

P0-1 · 背景音乐自动播放回归 已上线
index.html:740-742 加载即执行 initAudio(); tryPlay();，且 :714-720 挂了 document 一次性 click 兜底 —— 点击页面任意位置都会触发播放。preload='auto' 使 3.1MB mp3 首屏即拉取。08-25 曾明确移除，08-29 17:07 被加回。回滚源：index.html.bak-20260829-1707（「懶加載，默認關閉」版，已被 git 跟踪并推远端）。
P0-2 · pay.paomfz.com 返回 403 主转化路径断裂
index 上 2 个 Purchase 按钮（导航 + Hero）全指向 https://pay.paomfz.com/，均返回 403 Forbidden（Cloudflare challenge 页面）。用户无法完成购买转化。
P0-3 · mall.909net.cn 不可达 Hero「店鋪」按钮目标
curl --max-time 5 https://mall.909net.cn/ 返回 000（连接超时/被屏蔽）。Hero「店鋪」按钮指向 https://mall.909net.cn/links/629BA356，同样不可达。
P0-4 · VN 下载死链 整卡可点击放大误触
download.html:418 → /down/vn/PaoMianHax-Vn-211103-2(Pass123).zip 线上 404，本地无 down/vn/ 目录。整张卡片可点击（:605-611），误触面积大；且卡片标 Updating 却仍给可点下载按钮，状态与交互矛盾。
P0-5 · CI 隐患：rm -f CNAME 随时可能全站 404
.github/workflows/deploy-pages.yml 中有 rm -f CNAME，注释称「仅部署 github.io、保留 Cloudflare 主站」，但该前提不存在 —— 主站就在 GitHub Pages。每次部署都在删自定义域名凭证，随时可能解绑 → 全站 404。

🟠 P1 — 高优先级问题

P1-1 · 10 个 target="_blank" 缺 rel="noopener noreferrer"
index 6 个 + download 4 个。缺少 rel="noopener noreferrer" 会导致新窗口打开时原页面失去焦点、泄露 referrer、存在安全风险。
P1-2 · 死文件 69.0MB
down/ph/7A638484.zip + down/speed/×3。down/speed/ 三份 MD5 完全相同 12042ea173，同一文件复制三遍，纯浪费 25.4MB。在用仅 2 个（ph/9D759C3.zip 31.1MB + we/5C72CA.zip 29.1MB）。
P1-3 · CSS 重复 51%
download 16,614 字符中 6,171 字符与 index 选择器+声明完全相同（64 同名 / 61 条一致）。建议抽 static/site.css，但会破坏「单文件自包含」特性，需权衡。
P1-4 · 404.html 缺 DOCTYPE（三页唯一）
viewport 禁止缩放、lang="en" 但正文中文、用 h5 当主标题、0 处 aria-label、无 main/nav/footer。download.html 缺 h1。
P1-5 · 零安全响应头
HSTS / CSP / XFO / XCTO / Referrer-Policy 全无。另存在非预期的 Access-Control-Allow-Origin:*。可在 Cloudflare 面板加响应头规则解决，无需改代码。
P1-6 · .git 1.5GB / 463 loose object / in-pack: 0
从未 gc。55 个 >1MB blob 合计 1433MB，46 个 >25MB。down/ 历史 47 个版本（ph 31 + we 15 + speed 1）。
P1-7 · index.html.bak-20260829-1707 被 git 跟踪并推远端
根目录备份文件被提交并发布到线上，且线上可直接访问。.gitignore 未忽略 *.bak*。
P1-8 · robots.txt 是 Cloudflare 注入的 content-signals 模板
返回 200 但 1248B 全注释，零有效规则。sitemap.xml 404。
P1-9 · 页脚 "since 2099" 占位文本未改（两页都有）
明显占位符，暴露项目不成熟。
P1-10 · 支付渠道 mall.909net.cn（境内域名）与页脚 "Except China" 声明矛盾
合规风险。且 index 页脚漏写 "(Except China)"，两页声明不一致。
P1-11 · 两页 Modal 无焦点陷阱
打开后 Tab 可跑到背景内容，关闭后焦点不回原位。键盘与读屏用户完全不可达。
P1-12 · .dl-card 整卡 click 但无 role/tabindex/键盘事件
键盘与读屏用户完全不可达。

🏗️ 部署架构

用户请求 → Cloudflare（DNS + 反向代理 + DDoS 防护 + 缓存）
回源 → GitHub Pages（Fastly CDN，边缘节点在东京/孟买间漂移）
CI 触发 → push main → .github/workflows/deploy-pages.yml → 实测 59 秒完成部署
铁证 → X-GitHub-Request-Id + x-github-edge-region + Via: 1.1 varnish + X-Served-By: cache-* + X-Fastly-Request-ID

Cloudflare 上无独立站点副本，纯转发层。GitHub Pages 自动采用根目录 404.html 作自定义 404 页。
