### 磨砂（frosted）vs 液态（liquid）的本质差异 —— 可复用
| | 液态玻璃 v3 | 磨砂玻璃 v6 |
|---|---|---|
| saturate | **250%**（高饱和、彩色光斑透出来、边缘色散） | **140%**（低饱和、柔和不刺眼） |
| blur | 45px | 28px（够模糊就够，过大反而糊成一片） |
| 噪点 | .05 | **.055，砂感主要来源**（磨砂 vs 光面的视觉差异就在表面颗粒） |
| 玻璃本体 | 深半透 `rgba(24,27,38,.12)` | 浅半透 `rgba(255,255,255,.055)`（深底上玻璃比背景亮） |

### 深底 / 白底的玻璃厚度表达正好相反（重要）
- **白底**：玻璃比背景暗 → 顶部亮高光 + **底部内暗边** `rgba(31,38,79,.10)`
- **深底**：玻璃比背景亮 → 顶部受光高光 + **底部内亮边** `rgba(255,255,255,.06)`
- 两者都遵循同一原理：**上受光、下反射**，只是反射在暗背景下显亮、在亮背景下显暗

### hover 的 brightness 方向也相反
- 深底上 `brightness(1.22~1.28)` 提亮有效，不会过曝（v6 用这个值）
- 白底上必须压到 `1.03~1.04`，否则打到纯白失层次（v5 用这个值）

### 对比度（深底重算，全部远超 AA）
