## 全站视觉重构 v4 — 去 AI 同质化（Editorial Material System）

**需求**：用户判定旧版（macOS Liquid Glass v3）是「AI 把液态玻璃理解成固定视觉模板」，要求弱化玻璃感、保留其作为材质语言。目标：liquid glass + experimental editorial + asymmetric composition。

**诊断出的 AI 同质化信号（旧版）**
- 5 层蓝/紫/青/粉 radial + 30s 循环漂移的渐变底
- 全站同一档玻璃（blur 45 / sat 250%），玻璃当默认皮肤
- 圆角统一 18/24/32px；导航·按钮·徽章全是 pill
- 所有卡片 hover translateY(-7px)+scale+brightness 统一抬升
- 按钮镜面扫光、404 shine sweep / floaty / 音乐图标旋转 = 与状态无关的呼吸动效

**新体系（三页统一）**
- 五层：L0 背景（静止暖光 + 8 栏栅格线 + 噪点）／L1 内容（实心与透明并存，hairline 分隔）／L2 工具（导航·音乐·返回顶部，blur 16 α.84）／L3 浮层（弹窗，blur 28 α.94）／L4 强调（朱红）
- 玻璃只出现在 L2/L3；下载卡因背景单纯降到 blur 8 / α.045
- 色彩：暖石墨 #0A0908 + 暖白纸 #F0EAE1 + 唯一强调色朱红 #E8501A，去掉全部蓝紫渐变
- 圆角刻意不一致：容器 0–3px、控件 2px、只有状态点才是圆；`--radius-pill` 直接改 2px 一次性去胶囊
- 排版：等宽字体（mono）承担编号/元信息，CSS counter 生成 `01 — FUNCTION`、`01/02/03/04` 编号清单
- 非对称：Hero 左主文+右刻度轨；features 12 栏错位（1-7 / 8-12 / 2-6 / 7-11）；community 社群左 4 栏、影片右 7 栏；下载卡垂直错落 0/40/80px；404 左侧主文+右侧刻度轨+裁切的巨大 404 数字
- 动效只服务状态：hover 改为 hairline 变色 / 箭头位移；移除全部 scale、translateY、glow、scan、float

**执行方式（可复用）**
把新 CSS 写入 `.workbuddy/tmp/*.css`，再用 Python 正则只替换 `<style>...</style>` 块 —— HTML body 一字不改，脚本与文案零风险。已用脚本校验三页 body 与备份逐字节相同、CSS 花括号平衡；Edge 无头 dump-dom 冒烟无 JS 报错。

- CSS 副本：`.workbuddy/tmp/{index,download,404}.css`
- `meta theme-color` 由 #0b0d14 同步为 #0A0908
- 404 由浅色粉紫改为深色暖石墨，与全站统一；背景 SVG 降饱和+大模糊作环境反射源
